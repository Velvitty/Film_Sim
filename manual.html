이것만으로 충분합니다

🎞️

Portra, Kodachrome, Velvia, HP5, CineStill 등 필름 애호가라면 누구나 아는 이름들을 디지털로.
⚡
빠른 처리 속도
Canvas WebGL 가속으로 고해상도 이미지도 수 초 내에 처리.
🔒
완전한 프라이버시
서버 전송 없음. 이미지는 브라우저 메모리 안에서만 처리됩니다.
📱
반응형 UI
PC, 태블릿, 모바일 — 모든 화면에서 최적화된 경험.
💾
JPG 원클릭 다운로드
필터 적용 결과를 즉시 JPG로 저장. 파일명에 필름명이 자동으로 포함됩니다.
🪵
실시간 처리 로그
픽셀 처리 과정을 실시간으로 확인하는 콘솔 패널 내장.
🌗
비포/애프터 비교

✦ 사용 방법

세 번의 클릭으로
끝납니다

1

사진을 드래그하거나 클릭해서 올려요

JPG, PNG, WebP 등 일반적인 이미지 포맷을 모두 지원합니다. 드래그 앤 드롭도 OK.

2

마음에 드는 필름을 고르고 강도를 조절해요

16종 필름 프리셋 중 하나를 클릭하고, 슬라이더로 강도를 조절한 뒤 적용 버튼을 눌러보세요.

3

다운로드 버튼으로 JPG를 저장해요
