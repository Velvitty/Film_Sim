# Film Filter Studio — Film Science Engine v2.0

브라우저에서 사진에 필름의 색감·입상성·할레이션과 빈티지 렌즈의 광학 효과를 적용하는 사진 처리 도구입니다. sRGB 이미지를 선형 광량으로 변환한 뒤 필름 특성곡선과 노이즈 모델을 적용하고 JPEG로 저장합니다.

**필름 포맷, 그레인·할레이션 개별 조절, 렌즈 수차, 처리 해상도 설정**을 함께 제공해 사진의 색감과 질감을 세밀하게 조절할 수 있습니다.

## 주요 기능

- 컬러·슬라이드·흑백 필름 프리셋 13개
- 필름별 ISO, 유제, 감마, 입상성, 할레이션 등 설정값 표시
- 필름 룩 0~100%, 그레인·할레이션 각각 0~250% 조절
- 하프프레임·35mm·중형·대형 포맷에 따른 질감 크기 조절
- 보정 없음과 7가지 빈티지 렌즈 모델, 수차 세기 0~150%
- 원본 / 최대 24MP / 최대 12MP / 최대 6MP 처리 해상도 선택
- 원본·결과 비교, 단계별 진행 로그, JPEG 다운로드

## 사용 기술

| 기술 | 용도 |
| --- | --- |
| HTML / CSS / Vanilla JavaScript | UI와 처리 상태 관리 |
| FileReader / Image / Canvas 2D | 파일 읽기, 픽셀 접근, 이미지 출력 |
| Float32Array / LUT | 선형 RGB·밀도 계산과 특성곡선 조회 |
| 자체 이미지 처리 함수 | 블러, 리샘플링, 노이즈, 할레이션, 렌즈 수차 |
| localStorage | 사용권 동의 상태 저장 |
| Google Fonts | 웹 폰트 |

서버, API 키, 외부 JavaScript 프레임워크, 패키지 설치나 빌드 과정이 필요하지 않습니다.

## 실행 방법

**Code → Download ZIP**으로 내려받아 압축을 풀고 `index.html`을 브라우저에서 여세요.

Git과 Python 3가 설치되어 있다면 로컬 서버로 실행할 수도 있습니다.

```sh
git clone https://github.com/Velvitty/Film_Sim.git
cd Film_Sim
python3 -m http.server 8000 --bind 127.0.0.1
```

- 프로그램: <http://localhost:8000/index.html>
- 소개 페이지: <http://localhost:8000/manual.html>

`CNAME`에는 배포용 도메인 `film.yeon.at`이 설정되어 있습니다. 로컬 실행에는 이 도메인이 필요하지 않습니다.

## 사용 방법

1. 처음 표시되는 사용권 계약서에 동의합니다.
2. JPG·PNG·WebP 등 브라우저에서 열 수 있는 사진을 업로드합니다.
3. 필름을 선택하고 **선택한 필름의 특성** 패널을 확인합니다.
4. **필름 룩 세기**, **입상성(그레인)**, **할레이션**을 조절합니다.
5. **필름 포맷**을 선택합니다. 같은 이미지에서 포맷이 커지면 프레임 대비 입자가 더 작아지도록 계산합니다.
6. 필요하면 빈티지 렌즈와 수차 세기를 선택합니다. 기본 렌즈는 **현대 APO 렌즈 (보정 없음)**입니다.
7. 처리 해상도를 선택하고 **필터 적용하기**를 누릅니다. 기본값은 **최대 12MP**입니다.
8. 결과를 원본과 비교한 뒤 **다운로드**로 JPEG를 저장합니다. 설정 변경 후에는 다시 적용하세요.

## 프리셋과 설정

| 항목 | 선택지 |
| --- | --- |
| 컬러 네거티브 | Portra 400, Pro 400H, Superia 400, Gold 200, ProImage 100, Ektar 100, Natura 1600 |
| 슬라이드 | Velvia 50, E100D, Kodachrome 64 |
| 영화용 필름 계열 | Cinestill 800T |
| 흑백 | HP5 Plus, Kentmere 400 |
| 필름 포맷 | 하프프레임 18×24, 35mm 36×24, 중형 645, 중형 6×7, 대형 4×5 |
| 렌즈 | 현대 APO, 테사형, 대구경 더블가우스, 58mm 스월보케, 논코팅 트리플렛, 토륨 렌즈, 페츠발, 플라스틱 토이 |

필름 포맷 선택은 질감의 상대 크기를 계산하는 기준입니다. 이미지를 해당 종횡비로 자르는 기능은 아닙니다. 프리셋 수는 현재 코드 기준 13개이며 `manual.html`의 “16종” 소개 문구와 차이가 있습니다.

## 처리 파이프라인

1. sRGB 역감마와 선형 광량 변환
2. 색수차·주변부 수차·글로우·플레어·비네팅 등 렌즈 효과
3. 할레이션과 유제 내 산란의 근사
4. 분광감도 매트릭스, H&D 특성곡선, 채널 간 효과와 색조 변화
5. 밀도에 따라 달라지는 그레인과 색 입상성
6. 에지 인접효과, 염료 확산, 베이스 포그 등 후처리
7. 출력 색 변환, 원본과 혼합, JPEG 인코딩

이 과정은 코드에 정의한 수치 모델을 이용한 시각적 시뮬레이션입니다. 실물 필름이나 렌즈의 결과를 완전히 재현하거나 손실된 원본 정보를 복원한다고 보장하지 않습니다.

| 코드 구성요소 | 역할 |

## 출력·데이터 처리·문제 해결

- 출력은 품질 인자 `0.96`의 JPEG이며, 파일명은 `<필름 이름>_<타임스탬프>.jpg`입니다.
- 해상도 제한을 선택하면 큰 사진을 해당 픽셀 수 이하로 비율 유지 축소합니다. 원본 크기로 저장하려면 **원본 그대로**를 선택하세요.
- 사진은 브라우저 메모리에서 처리되며 서버 업로드 기능은 없습니다. 폰트는 Google Fonts에서 요청합니다.
- 사용권 동의 상태와 동의 시각은 `localStorage`에 저장됩니다.
- 처리 중 여러 부동소수점 버퍼를 사용하므로 메모리가 부족하면 6MP 또는 12MP로 낮추세요. 파일 용량 제한이 없다는 안내는 브라우저 자원 제한이 없다는 뜻이 아닙니다.
- RAW·HEIC 등의 지원은 브라우저에 따라 다릅니다. 읽기 오류가 나면 JPG·PNG·WebP로 변환하세요.
- 원본 EXIF를 결과에 복사하는 기능은 없으며 JPEG 출력은 투명도를 보존하지 않습니다.
